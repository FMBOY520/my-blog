## 标题标签

```HTML
<h1>1级标签</h1>
<h2>2级标签</h2>
<h3>3级标签</h3>
<h4>4级标签</h4>
<h5>5级标签</h5>
<h6>6级标签</h6>
```

## 段落标签

```HTML
<p>我是一段文字</p>
```

## 换行标签

```HTML
<br>
```

## 水平线标签

```HTML
<hr>
```

## 超链接标签

```HTML
<a href="https://blog.fmboy.com" target="_blank">超链接</a>
```

#### target属性 目标网站的打开方式

| 值     | 功能                                   |
| ------ | -------------------------------------- |
| _self  | 默认值，在当前窗口中跳转（覆盖原网页） |
| _blank | 在新窗口中跳转（保留）                 |
